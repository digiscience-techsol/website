## A. LinkedIn post for Day 1

### AI readiness before AI spend

AI budgets can disappear quickly when the first question is "which tool should we buy?"

A better first question is: "which workflow is ready?"

Before recommending any AI build, I like to score five things:
- business value
- data availability
- cloud readiness
- governance risk
- pilot feasibility

If those are unclear, the safest next step is an AI readiness assessment, not a build.

Soft CTA: If you are exploring AI, start by scoring one workflow.

Suggested hashtags: #AIReadiness #EnterpriseAI #DigitalTransformation

## E. Tracker update instructions

- Status

Recommended Day-1 status updates:
- Connection request sent: set Status to Connection Sent.
- DM sent after accepted connection: set Status to Message Sent.
- No response after first touch: set Next Follow-up Date to Day 2.
- Reply received: set Status to Replied and add the exact objection or interest signal in Notes.
