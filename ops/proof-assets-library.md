## Scorecard Dimensions

| Dimension | Question |
| --- | --- |
| Business value | Does the use case improve revenue, cost, risk, productivity, or customer experience? |
| Data readiness | Are data sources available, classified, and usable? |
| Cloud readiness | Is the target Azure, AWS, or GCP environment ready for secure AI workloads? |
| Governance readiness | Are owners, reviewers, approval gates, and audit needs clear? |
| Integration effort | Which systems, APIs, documents, or workflows must connect? |
| Pilot feasibility | Can a controlled proof be delivered with limited scope and measurable criteria? |

## ROI Calculator Inputs

- Users impacted
- Hours saved per user per month
- Fully loaded hourly cost

- Cycle-time improvement
- Monthly AI operating cost
- Setup cost
- Adoption assumption
