# Customer Delivery Checklist

Date: 2026-05-25
Status: Internal operations checklist. Do not publish.

## Discovery Call Checklist

- Confirm customer company, industry, and primary contact.
- Confirm workflow owner and decision owner.
- Identify one workflow with visible manual effort, delay, rework, risk, or cost leakage.
- Capture current process steps.
- Capture users affected.
- Capture systems involved.
- Capture data sources involved.
- Capture current baseline metric.
- Capture desired business outcome.
- Capture security, privacy, and compliance constraints.
- Confirm what must not be touched in a pilot.
- Confirm whether the customer wants assessment, pilot, governance review, or platform readiness.
- Agree next step and owner.

## AI Readiness Assessment Checklist

- Define one workflow boundary.
- Score business value.
- Score manual effort or delay.
- Score baseline metric clarity.
- Score data availability.
- Score data quality.
- Score cloud/platform readiness.
- Score security and compliance risk.
- Score human approval path.
- Score integration feasibility.
- Score ROI signal.
- Recommend one of:
  - AI Readiness Assessment continuation
  - 45-Day Industry AI Pilot
  - Responsible AI Governance Review
  - Secure AI Cloud Platform
  - Defer / not worth piloting now

## Data Readiness Checklist

- Data owner identified.
- Source systems listed.
- Sample/test data path approved.
- Data format known.
- Data quality issues identified.
- Data sensitivity classified.
- PII/PHI/financial/confidential data flags captured.
- Masking or redaction needs captured.
- Retention constraints captured.
- Allowed processing region/location captured.
- Data refresh pattern captured.
- Access method approved.

## Cloud Readiness Checklist

- Target cloud or hosting environment identified: Azure, AWS, GCP, hybrid, or other.
- Identity and access model known.
- Least-privilege access path defined.
- Network constraints captured.
- Logging and monitoring path identified.
- Deployment path identified.
- Secrets management path identified.
- Cost monitoring path identified.
- Backup/rollback needs captured.
- Customer IT owner identified.

## Security / Governance Checklist

- Security owner identified.
- Compliance owner identified.
- Access approval owner identified.
- Audit trail requirement captured.
- Human approval points defined.
- Model/vendor approval constraints captured.
- Prompt/data leakage risks captured.
- Encryption requirements captured.
- Role-based access requirements captured.
- Incident/rollback route captured.
- No passwords, tokens, private keys, unrestricted admin access, or production data dumps requested.

## Pilot Kickoff Checklist

- Scope approved.
- Success metric approved.
- Baseline metric captured.
- Pilot users identified.
- Data access approved.
- Cloud/platform access approved.
- Security review completed or scheduled.
- Weekly review cadence booked.
- Delivery owner assigned.
- Customer owner assigned.
- Risks documented.
- Go/no-go date agreed.
- Exclusions documented.

## Weekly Review Checklist

- Review completed work.
- Review blockers.
- Review data/access issues.
- Review security/governance issues.
- Review pilot metric progress.
- Review user feedback.
- Review cost/usage signals.
- Confirm next week actions.
- Update risk register.
- Update go/no-go confidence.

## Handover Checklist

- Final workflow summary completed.
- Architecture summary completed.
- Data map completed.
- Access list documented.
- Security controls documented.
- Governance controls documented.
- Runbook completed.
- Monitoring/cost notes completed.
- User feedback summarized.
- Success metric outcome recorded.
- Risks and limitations recorded.
- Scale / revise / pause / stop recommendation completed.
- Customer owner and next decision date confirmed.
