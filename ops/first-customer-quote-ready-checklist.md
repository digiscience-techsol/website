# First Customer Quote Ready Checklist

Status: Internal quote-readiness checklist. Do not publish. Do not send.

| Check | Status | Notes |
| --- | --- | --- |
| Proposal template ready | Yes | Proposal dry run exists with founder-approved commercial defaults and placeholders. |
| Invoice draft ready | Yes | Invoice dry run exists with placeholders only. |
| Kickoff checklist ready | Yes | Kickoff dry run exists with placeholder roles, cadence, final output, and go/no-go decision. |
| Sensitive billing details pending | Yes | Legal entity, billing address, tax/GST handling, bank instructions, invoice email, invoice numbering, payment due date, and authorized signatory remain pending. |
| Buyer-specific recipient pending | Yes | No buyer-specific recipient is approved for use in this checklist. |
| Quote can be drafted | Yes | Draft only, using placeholders and founder-approved commercial defaults. |
| Invoice can be drafted with placeholders | Yes | Draft only; no actual bank/tax/payment details in Git. |
| Invoice can be issued only after founder provides private details | Yes | Final invoice requires founder-provided private billing, tax, and payment details. |
| Customer start can happen only after payment/acceptance | Yes | Kickoff requires customer acceptance and payment confirmation unless founder approves an exception. |

## Current Approved Defaults

- Offer: AI Readiness Assessment.
- Price: INR 1,00,000 + applicable taxes.
- Payment path: manual invoice + company bank transfer.
- Proposal owner: DigiBot drafts, founder approves.
- Billing owner: founder handles billing.
- Signature method: email acceptance for assessment; signed PDF/SOW for pilot.
- Razorpay/Stripe: deferred.

## No-Send Control

No quote, proposal, invoice, outreach, form submission, LinkedIn action, or customer contact is approved by this checklist.
