# Website Update SOP

## Purpose
This SOP defines how DigiScience Techsol website changes will be requested, implemented, reviewed, and released.

## Roles
- Founder: defines business direction and approves major positioning changes.
- Assistant / Technical Lead: converts business direction into content, code, and documentation updates.
- GitHub repository: source of truth for website code.
- Cloudflare: production deployment platform connected to GitHub.

## Standard workflow
1. Capture the website requirement in GitHub issue #2 or a related website issue.
2. Convert the requirement into page copy, code changes, or documentation updates.
3. Make changes in a branch where possible.
4. Validate the page content and links.
5. Publish through the GitHub to Cloudflare deployment path.
6. Record the change summary in the issue.

## Update categories
- Homepage positioning
- Service catalog page
- Industry solution page
- AI governance page
- AI readiness assessment page
- Proof asset page
- Contact and lead capture update
- SEO metadata update
- Navigation and footer update

## Current strategic direction
DigiScience Techsol should be positioned as an AI-first cloud transformation partner helping enterprises build secure, governed, industry-specific AI solutions on Azure, AWS, and GCP.

## Current control issue
Issue #2 is the operating channel for website update coordination.
