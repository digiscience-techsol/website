# DigiScience Techsol website

Source for the public [DigiScience Techsol website](https://digisciencetechsol.com/).

DigiScience helps teams assess one defined business or technology problem and choose a practical next step across workflow improvement, automation, AI, cloud or platform changes.

## Public service and examples

- [Solution Assessment](https://digisciencetechsol.com/solution-assessment): problem framing, options comparison, recommendation and implementation brief. Implementation is scoped separately.
- [Synthetic enquiry-triage demonstration](https://digisciencetechsol.com/guides/manufacturing-enquiry-workflow/#synthetic-triage): fictional inputs, routing rules, reproducible source and tests, and explicit limitations. This is not a customer result.
- [Representative assessment output](https://digisciencetechsol.com/proof-assets/sample-solution-assessment): a synthetic example of the written decision package.
