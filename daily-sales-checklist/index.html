Daily sales checklist

Run first-customer acquisition every working day

This checklist converts the GTM strategy into a repeatable founder routine. Use it with the prospect tracker and message bank.

Download trackerOpen messages

Every working day

  • Publish or comment on one LinkedIn post.
  • Send 10 targeted connection requests.
  • Send 5 personalized messages.
  • Send 2 follow-up emails.
  • Update prospect tracker status, next date, and next action.
  • Review hot/warm leads from form submissions and outbound replies.
  • Schedule next actions for every active lead.
  • Capture objections in the tracker notes.
  • Improve one message based on replies or silence.

Daily quality rule

Do not send a message unless it names a buyer role, a plausible workflow pain, and one low-friction next step. A smaller number of precise messages is better than generic volume.
